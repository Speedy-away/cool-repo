# Scooby Community Downloads

Browse and search the collection at https://scoobymenu.cc/community/

This repository stores asset downloads and catalog metadata. Its index.html redirects visitors to Scooby Community. Direct raw file URLs remain usable.

## Organization

- downloads/<game>/<category>/ — installable configs, languages, themes, maps, textures and skies
- previews/cs2/ — model artwork
- catalog/library.json — website download catalog
- catalog/cs2-models.json — complete original CS2 model metadata, hashes, credits and source terms
- catalog/gta5-maps-source.json — bundled map collection source manifest

Games use gta5, rdr2, cs2, fivem, redm and l4d identifiers. Categories without imported files remain available on the website. No game-project source code, DLLs, executables, build outputs or credentials are included.

Third-party CS2 model payloads retain their publisher's download URLs and terms. Donor-generated variants are installed through Scooby's in-game Repo, using the matching local CS2 installation. The active website catalog contains native Scooby resources and attributed third-party GTA mod listings. Nenyoo-only theme bundles remain stored for source reference in catalog/source-theme-packs.json and are excluded from catalog/library.json. Native Stand collections supported by Scooby are separate from those archived Nenyoo imports. Theme images are currently disabled in the site catalog.

## Rebuilding

From the dogsite checkout, run:

    node tools/build-community-library.cjs --target <absolute-path-to-cool-repo> --dry-run
    node tools/build-community-library.cjs --target <absolute-path-to-cool-repo>
    node tools/build-community-library.cjs --target <absolute-path-to-cool-repo> --check

Use --source-root <GitHub-directory> when the game projects are not sibling checkouts. The importer only reads explicit asset folders, preserves package paths and author metadata, rejects path traversal and symbolic links, and never deletes existing repository files.

Imported Lua downloads are excluded from the active catalog and are not regenerated by this importer.

Native GTA 5 paintjobs are saved colour JSON presets from C:/scooby/GTA5/LSC/PaintJobs. Downloads preserve their original bytes and filenames. Install them into that folder or its matching colour subfolder, enter a vehicle, then use LSC Save/Load Paint Jobs. Livery images and GTA5-Mods paintjob listings use the separate liveries category. Use --paintjobs-root <folder> to rebuild from a different explicit native preset library.

Native RDR2 addon ZIPs retain install.xml, declared ped metadata, all streaming dependencies and original credits. Import through C:/scooby/RDR2/Addon Archives and the Addons/Replacements page. Editing projects, disabled replacements and backups are excluded. Use --rdr2-addons-root <folder> to select another explicit native asset library. Public RedM object resources remain original commit-pinned author downloads with verified byte hashes; their server/archetype requirements are recorded separately from native RDR2 compatibility.

## Bounded catalog refresh

After a full import, update source-only theme metadata and native ClickUI color/Stand additions without rebuilding the existing library:

    node tools/build-community-library.cjs --target <absolute-path-to-cool-repo> --refresh-catalog

ClickUI color presets export the host’s built-in palette data into color fields explicitly accepted by that host’s saved-theme loader. Back up the current theme before loading: native loader defaults and migrations may also apply. These are color presets rather than full copies of every native preset effect. Stand ZIP files retain their original profiles, scripts, supporting artwork and checksums. Shared Stand payloads are stored once under downloads/shared/themes/stand.
